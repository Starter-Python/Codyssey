# 과제 수행 과정: Gemini와 Kakao API를 연결한 국내 여행 추천 프로그램

이 프로그램은 날짜 하나를 받아 **Gemini 구조화 추천 → Kakao 맛집 검색 → Gemini Markdown 리포트**로 이어지는 데이터 파이프라인을 만듭니다. 핵심은 AI의 자유 형식 문장을 그대로 다음 단계에 넘기지 않고, JSON으로 검증한 뒤 외부 장소 검색 API의 입력으로 연결하는 것입니다.

## 0. 한 줄 요약과 비유

> **여행사 직원이 하루치 일을 자동으로 처리하는 도구**라고 생각하면 쉽습니다.

1. **1단계(추천)**: 직원이 AI(Gemini)에게 "가을에 가기 좋은 국내 도시 추천해줘"라고 물어봅니다. AI는 답을 자유 문장이 아니라 `{도시, 날씨, 행사, 이유}` 칸막이(JSON) 형태로 줍니다.
2. **2단계(맛집 찾기)**: 직원이 그 도시 이름 뒤에 "맛집"을 붙여 카카오 지도에서 최대 5곳을 검색합니다.
3. **3단계(보고서 작성)**: 1단계 답변과 2단계 맛집 목록을 함께 들고 AI에게 "이걸로 여행 리포트 써줘"라고 시켜 Markdown 문서를 완성합니다.

**주의할 점 2가지**

- 중간에 뭐가 실패해도(맛집 검색 실패, AI 오류 등) 프로그램은 멈추지 않고 오류 내용을 기록한 뒤 끝까지 진행합니다. 그래서 결과 파일이 항상 남습니다.
- API 키(비밀번호 같은 값)는 코드에 직접 쓰지 않고 `.env` 파일에만 보관합니다. `.env`는 GitHub에 올라가지 않도록 설정되어 있습니다.

## 1. 역할을 세 단계로 분리하기

| 단계 | 입력 | 처리 | 출력 | 다음 단계에 전달하는 값 |
|---|---|---|---|---|
| 1차 추천 | `-date` | Gemini `generateContent` 호출과 JSON 검증 | 지역·날씨·행사 후보·이유 | `recommended_city` |
| 맛집 검색 | `recommended_city` | Kakao Local 키워드 검색 | 표준화한 맛집 목록 | `restaurants` |
| 최종 리포트 | 추천 JSON + 맛집 + 오류 | Gemini `generateContent` 호출 | Markdown 여행 리포트 | `results/` 파일 |

`argparse`와 `datetime.strptime()`는 API 호출 전에 날짜 형식과 실제 달력 날짜를 검증합니다. 따라서 `2026-02-30`처럼 존재하지 않는 날짜는 즉시 사용법과 함께 거부됩니다.

## 2. Gemini JSON을 안전하게 생성하고 검증하기

1차 Gemini 호출은 `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`로 수행합니다. `request_gemini()`은 `x-goog-api-key` 헤더에 환경변수의 키를 넣고, `generationConfig`에 `responseMimeType: application/json`과 `responseJsonSchema`를 전달합니다. Gemini API는 JSON Schema에 맞춘 구조화 출력을 지원하므로, 다음 단계에 사용할 데이터를 예측 가능한 형태로 받을 수 있습니다.[1]

```json
{
  "recommended_city": "강릉",
  "weather": "가을 초입에는 일교차가 있어 얇은 겉옷이 필요합니다.",
  "events": ["지역 가을 문화행사 후보", "해변 산책 프로그램 후보"],
  "reason": "선선한 날씨에 바다와 도심을 함께 즐기기 좋습니다. ..."
}
```

`validate_recommendation()`은 JSON 파싱 후에도 필수 키와 타입을 다시 확인합니다.

| 검증 대상 | 이유 |
|---|---|
| `recommended_city`, `weather`, `reason`이 비어 있지 않은 문자열 | 검색어와 리포트 문장에 안전하게 사용 |
| `events`가 문자열 배열 | 행사 후보를 반복 출력할 때 형식 오류 방지 |
| 네 필수 키 모두 존재 | 다음 단계의 입력 누락 방지 |

JSON이 깨지거나 키가 누락되면 보정 프롬프트로 최대 두 번(총 3회 시도) 재시도합니다. 세 번째에도 실패하면 무한 반복하지 않고 오류를 알립니다.

> **리포트 잘림 방지 (2026-10 수정)**: Gemini 3.x 플래시 모델은 응답 전에 내부 `thinking`(추론) 토큰을 먼저 소비하는데, 이 토큰이 `maxOutputTokens` 한도를 잠식해 최종 리포트 본문이 중간에 잘리는 현상이 있었습니다. `request_gemini()`의 `generationConfig`에 `thinkingConfig: {"thinkingBudget": 0}`을 추가해 thinking을 비활성화했고, 이후 리포트가 온전한 길이로 생성됨을 확인했습니다.

## 3. Gemini 무료 API 키와 환경변수 관리

Gemini API 키는 Google AI Studio에서 발급해 `.env`의 `GEMINI_API_KEY`에만 저장합니다. 무료 등급은 개발과 소규모 프로젝트를 위한 제한된 모델·요청량을 제공하며, 사용 가능한 모델과 한도는 계정·시점에 따라 달라질 수 있습니다.[2] 기본 모델은 `gemini-3.5-flash`이고, 계정에서 지원하는 다른 모델이 필요하면 `GEMINI_MODEL` 환경변수로 바꿀 수 있습니다.

| 항목 | 코드에서 읽는 방식 | GitHub 커밋 여부 |
|---|---|---|
| Gemini API 키 | `os.getenv("GEMINI_API_KEY")` | 아니오 |
| Kakao REST API 키 | `os.getenv("KAKAO_REST_API_KEY")` | 아니오 |
| 키 이름 예시 | `.env.example` | 예, 실제 값 없음 |

`.env`는 `.gitignore`에 등록되어 있습니다. 실제 키를 코드·README·결과 파일에 쓰지 않으므로, 키 교체 시 코드 재커밋도 필요하지 않습니다.

## 4. 추천 도시를 Kakao Local 검색으로 연결하기

검증된 `recommended_city`는 `"{도시} 맛집"` 검색어가 됩니다. Kakao Local 키워드 장소 검색은 GET 방식이며, REST API 키를 `Authorization: KakaoAK {REST_API_KEY}` 헤더에 넣습니다.[3]

```python
requests.get(
    KAKAO_KEYWORD_URL,
    headers={"Authorization": f"KakaoAK {kakao_key}"},
    params={"query": f"{city} 맛집", "size": 5},
    timeout=20,
)
```

`normalize_place()`는 Kakao의 원래 응답 필드를 과제 공통 구조로 바꿉니다.

| Kakao 응답 | 저장 필드 |
|---|---|
| `place_name` | `name` |
| `road_address_name` 또는 `address_name` | `address` |
| `category_name` | `category` |
| `place_url` | `url` |
| `x`, `y` | `x`, `y` |

장소 검색이 0건이거나 인증·쿼터·네트워크 오류가 발생하면 빈 목록을 반환하고 `errors`에 원인을 남깁니다. 프로그램은 중단하지 않고 Gemini 최종 리포트 단계로 계속 진행합니다.

## 5. 최종 Gemini 리포트와 대체 리포트

두 번째 Gemini 호출에는 1차 추천 JSON, 맛집 목록, 오류 목록을 함께 전달합니다. 모델에는 추천 지역·이유·날씨·행사·맛집·1일 일정·오류 요약이라는 Markdown 제목을 반드시 포함하도록 지시합니다. 맛집 배열이 비어 있으면 정확히 `데이터 없음`을 표기하도록 해, 없는 맛집을 지어내지 않습니다.

최종 Gemini 호출이 실패하면 `fallback_report()`가 이미 확보한 데이터로 최소 Markdown 리포트를 생성합니다. 이 설계로 외부 API 일부가 실패해도 사용자가 확인할 수 있는 결과 파일을 남깁니다.

## 6. 오류 처리와 HTTP 메서드 이해하기

| 상황 | 처리 정책 |
|---|---|
| `GEMINI_API_KEY` 없음 | 즉시 종료하고 설정 방법 안내 |
| Gemini 401/403 | 키 또는 Google AI Studio 프로젝트 설정 점검 안내 |
| Gemini 429 | 무료 등급 요청 제한·쿼터 점검 안내 |
| Gemini JSON 파싱 실패 | 보정 프롬프트로 한 번 재시도 |
| Kakao 401/403/429·네트워크 오류 | 맛집을 빈 목록으로 처리하고 리포트 계속 |
| 최종 Gemini 오류 | 대체 리포트 생성 |

> **GET**은 조회 중심 요청으로 Kakao 장소 검색에 사용하고, **POST**는 JSON 본문을 보내 새 출력을 생성하는 Gemini 요청에 사용합니다. 이 과제는 GET으로 장소 데이터를 받고 POST로 AI 추천과 리포트를 생성합니다.

`redact_secrets()`는 오류 요약에 Gemini 또는 Kakao 키가 포함될 가능성을 줄이기 위해 환경변수 값과 일반적인 키 패턴을 `[REDACTED]`로 바꿉니다. `write_results()`는 추천 JSON, 맛집 배열, 오류 배열을 날짜별 JSON으로 저장하고, 최종 리포트는 별도 Markdown으로 저장합니다.
