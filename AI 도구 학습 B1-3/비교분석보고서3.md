# 프로젝트 1: 자동화 도구 비교 구현 (Make vs Zapier)

## 1. 워크플로우 개요

**주제:** Google Form 퀴즈 채점 자동 알림 시스템

> Google Form으로 10문제 퀴즈를 출제하고, 응답 제출 시 정답 개수를 계산하여
> **7개 이상이면 PASS / 미만이면 FAIL**을 Discord로 자동 알림하는 워크플로우

- **Trigger:** Google Form 응답 제출
- **조건 분기:** 정답 개수 ≥ 7 (PASS) / < 7 (FAIL)
- **Action 1:** Discord PASS 알림 전송
- **Action 2:** Discord FAIL 알림 전송

---

## 2. 도구별 구현 상세

### [Make 구현]
- **Trigger:** Google Forms – Watch Responses (응답 감지)
- **Router:** 정답 개수 조건으로 두 경로 분기
  - 경로 A: 정답 ≥ 7 → PASS
  - 경로 B: 정답 < 7 → FAIL
- **Action 1:** Discord – Send a Message (PASS 알림)
- **Action 2:** Discord – Send a Message (FAIL 알림)

📷 *구성 화면 캡처: `./images/make_workflow.png`*
📷 *실행 결과 캡처(PASS/FAIL 각 1회): `./images/make_result_pass.png`, `./images/make_result_fail.png`*

### [Zapier 구현]
- **Trigger:** Google Forms – New Response
- **Filter/Paths:** 정답 개수 조건 분기
  - Path A: 정답 ≥ 7 → PASS
  - Path B: 정답 < 7 → FAIL
- **Action 1:** Discord – Send Channel Message (PASS 알림)
- **Action 2:** Discord – Send Channel Message (FAIL 알림)

📷 *구성 화면 캡처: `./images/zapier_workflow.png`*
📷 *실행 결과 캡처(PASS/FAIL 각 1회): `./images/zapier_result_pass.png`, `./images/zapier_result_fail.png`*

---

## 3. 구현 과정 요약

1. Google Form으로 10문제 퀴즈 제작 및 정답 설정
2. 응답이 연결된 Google Sheets(또는 폼 응답)를 각 도구의 Trigger로 연결
3. 정답 개수를 산출하는 필드 매핑
4. 조건 분기(Make: Router / Zapier: Paths)로 PASS·FAIL 경로 구성
5. 각 경로에 Discord 메시지 Action 연결
6. PASS/FAIL 케이스를 각각 1회 이상 테스트하여 두 경로 실행 확인

---

## 4. 비교 분석표

| 비교 항목 | Make | Zapier |
|-----------|------|--------|
| **UI/UX** | 시각적 노드(블록) 기반, 흐름을 한눈에 파악 | 리스트형 단계 구성, 위→아래 순차적 |
| **설정 난이도** | 초기 학습 곡선 있음, 익숙해지면 유연 | 직관적, 초보자 진입 쉬움 |
| **조건 분기 방식** | Router로 다중 경로 시각적 분기 | Filter/Paths(유료 플랜에서 Paths 확장) |
| **연동 서비스 범위** | 광범위, 복잡한 데이터 변환 강점 | 앱 커넥터 수 매우 많음, 대중적 앱 강점 |
| **무료 플랜** | 월 1,000 Operations | 월 100 Tasks (Paths는 상위 플랜) |
| **실행 로그 확인** | 실행 히스토리에서 단계별 데이터 상세 확인 | Task History에서 성공/실패 확인 |

> ⚠️ 무료 플랜 수치는 정책 변경 가능성이 있으니 제출 전 실제 값 확인 권장

---

## 5. 각 도구의 장단점

### Make
- ✅ **장점:** 시각적 흐름 파악 용이, 무료 Operations 넉넉, 복잡한 분기·데이터 처리에 강함
- ❌ **단점:** 초기 학습 곡선, 용어(모듈·시나리오)가 낯설 수 있음

### Zapier
- ✅ **장점:** 매우 직관적, 빠른 구축, 방대한 앱 연동
- ❌ **단점:** 무료 Task 한도가 적음, 다중 분기(Paths)는 유료 플랜 필요

---

## 6. 상황별 적합성 의견

- **복잡한 분기·데이터 가공이 필요하거나 실행량이 많은 경우** → **Make** 추천 (무료 Operations 여유, Router 무료 사용)
- **빠르게 간단한 자동화를 만들고 싶거나 다양한 앱을 연결해야 하는 경우** → **Zapier** 추천
- **이번 퀴즈 채점 워크플로우처럼 분기가 필수인 무료 프로젝트**에서는 무료로 Router를 쓸 수 있는 **Make가 더 유리**했다.
