# [담당 3] AI 기반 브랜드 로고 시안 생성 보고서

## 1. 담당 기능 및 목적
- **담당 역할**: 담당 3 — 브랜드 로고 시안 자동 생성 및 파일 저장
- **기능 목적**: 
  - 담당 1(브랜드 기획)의 브랜드명, 업종, 타겟, 키워드, 분위기 정보와 담당 2(컬러 기획)의 메인/서브 컬러 팔레트 정보를 종합합니다.
  - Codyssey AI 이미지 생성 API(`gpt-image-1-mini`)를 활용하여 브랜드 정체성이 반영된 서로 다른 스타일의 로고 시안 3종을 자동 생성하고 PNG 파일로 저장합니다.
  - 최종 통합 담당자(담당 4)가 바로 호출할 수 있도록 저장된 파일의 경로 리스트를 반환합니다.

---

## 2. 입력 및 출력 데이터 규격

### 📥 입력 데이터 (Input)
담당 1과 담당 2로부터 전달받는 통합 브랜드 딕셔너리:
```json
{
  "brand_name": "Blooming",
  "industry": "친환경 화장품",
  "target": "20~30대 여성",
  "keywords": ["자연", "순수", "건강"],
  "tone": "따뜻하고 신뢰감 있는",
  "main_color": "#2E7D32",
  "sub_colors": ["#A5D6A7", "#FFF3E0", "#5D4037"]
}
```

### 📤 출력 데이터 (Output)
- **생성된 파일**: 지정된 폴더(`output/`)에 PNG 형식으로 저장
  - `logo_01.png` (미니멀 심볼형 로고)
  - `logo_02.png` (자연/유기적 라인아트형 로고)
  - `logo_03.png` (모던 엠블럼형 로고)
- **함수 반환값**:
```python
[
  "./output/logo_01.png",
  "./output/logo_02.png",
  "./output/logo_03.png"
]
```

## 3. 프롬프트 엔지니어링 전략 (로고 퀄리티 최적화)

이미지 생성 AI 모델이 브랜드 로고로서 실용적이고 직관적인 결과물을 낼 수 있도록 다음 3가지 전략을 적용했습니다:

1. **3가지 차별화된 디자인 콘셉트 적용**:
   - **스타일 1 (미니멀 심볼 & 아이콘형)**: 깔끔한 기하학적 심볼과 플랫 벡터 디자인.
   - **스타일 2 (자연/유기적 라인아트형)**: 섬세한 식물/곡선 모티브의 내추럴 라인아트.
   - **스타일 3 (모던 엠블럼형)**: 현대적인 시그니처 엠블럼과 여백의 미를 살린 디자인.

2. **로고 특화 프롬프트 제약 조건 설정**:
   - `pure solid white background`: 배경 분리(누끼) 및 브랜드 활용도를 극대화하기 위해 단색 화이트 배경 강제
   - `flat design, crisp vector graphics`: 복잡한 3D 렌더링이나 실사 사진 질감을 배제하고 로고 본연의 간결한 심볼 유도
   - 2번 담당자가 추천한 메인 컬러(`#2E7D32`) 및 서브 컬러 HEX 코드를 프롬프트에 직접 매핑하여 컬러 일관성 유지

## 4. 사용한 기술 및 API

| 구분 | 사용 기술 / 사양 | 상세 내용 |
| :--- | :--- | :--- |
| **API 엔드포인트** | `https://copa.codyssey.kr/api/v1/images` | Codyssey AI 이미지 생성 전용 엔드포인트 |
| **이미지 생성 모델** | `gpt-image-1-mini` | `size: 1024x1024`, `response_format: b64_json` |
| **인증 및 통신** | `Bearer Token`, `urllib.request` | 파이썬 표준 라이브러리를 사용하여 추가 패키지 없이 경량 통신 |
| **이미지 처리/저장** | `base64.b64decode` | Base64 바이너리 데이터를 즉시 PNG 파일로 디코딩하여 로컬 저장 |

## 5. 오류 처리 및 안정성 확보

1. **Codyssey 전용 Base64 디코딩 방식 적용**:
   - 웹 세션 전용 URL 대신 `response_format: "b64_json"`을 전달하여 `401 Unauthorized` 다운로드 오류를 원천 차단.
2. **개별 시안 단위 오류 격리 (`try-except`)**:
   - 3개의 시안 중 특정 프롬프트에서 일시적인 지연이나 오류가 발생하더라도, 전체 파이프라인이 중단되지 않고 다음 시안 생성을 계속 진행하도록 처리.
3. **폴더 자동 생성**:
   - 출력 대상 디렉토리(`output/`)가 없는 경우 `os.makedirs(output_dir, exist_ok=True)`로 자동 생성.

## 7. 문제점 및 해결 과정

- **문제점 1**: OpenAI 공식 URL 호출 시 `401 / 404` 에러 발생.
  - **원인 분석**: Codyssey에서 발급한 API 키(`sk-cody-live-...`)는 OpenAI 공식 서버가 아닌 Codyssey 전용 엔드포인트(`https://copa.codyssey.kr/api/v1/images`)에서 작동함.
  - **해결**: 엔드포인트를 Codyssey 전용으로 수정하고 `gpt-image-1-mini` 모델 지정.
- **문제점 2**: 이미지 다운로드 시 `401` 세션 에러 발생 이슈.
  - **원인 분석**: Codyssey 보안 정책상 이미지 URL은 웹 세션 전용이며 직접 다운로드가 차단됨.
  - **해결**: `response_format: "b64_json"` 옵션을 지정하여 base64 문자열 원본을 응답으로 받아 `base64.b64decode()`로 로컬 PNG 파일로 바로 저장하도록 수정 완료.
