# A1-1 | Python 콘솔 프롬프트 관리자

터미널에서 번호를 골라 프롬프트를 관리하는 콘솔 프로그램입니다.
추가 · 목록 · 카테고리 조회 · 검색 · 상세 보기 · 즐겨찾기 · 삭제 · 수정 · 조회수 Top · JSON 저장/불러오기 · Markdown 내보내기를 제공합니다.

> 기본은 실행 중 메모리에만 유지됩니다. 종료 후 다시 실행하면 기본 예시 10개로 초기화됩니다. 계속 쓰고 싶으면 메뉴 `11`로 저장하고 `12`로 불러오세요.
> `input()`을 쓰므로 반드시 **VSCode 통합 터미널**에서 실행하세요. Output·Debug Console에서는 안내 문구만 나옵니다.

## 빠른 실행

```bash
cd "AI 활용 학습 A1-1"
python3 prompt_manager.py
```

1. 메뉴 번호를 입력하고 Enter를 누릅니다.
2. 종료는 `14`를 입력합니다.
3. Python 3.10 이상, 외부 패키지 없이 동작합니다.

## 메뉴

| 번호 | 기능 | 동작 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력받아 저장합니다. 빈 입력은 다시 요청합니다. |
| 2 | 전체 목록 보기 | 번호·제목·카테고리·즐겨찾기(⭐)·조회수를 보여 줍니다. |
| 3 | 카테고리별 조회 | 고른 카테고리의 항목만 보여 줍니다. |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 든 항목을 찾습니다. |
| 5 | 상세 보기 | 번호를 골라 전체 내용을 보고 조회수 1을 기록합니다. |
| 6 | 즐겨찾기 추가/해제 | 번호를 골라 ⭐ 상태를 뒤집습니다. |
| 7 | 즐겨찾기 목록 | ⭐ 항목만 모아 봅니다. |
| 8 | 프롬프트 삭제 | 번호를 골라 확인(`y`) 후 삭제합니다. `n`이면 취소합니다. |
| 9 | 프롬프트 수정 | 번호를 골라 제목·내용·카테고리를 고칩니다. Enter면 유지합니다. |
| 10 | 조회수 Top 보기 | 조회수 상위 5개를 보여 줍니다. |
| 11 | JSON 저장 | 현재 목록을 `prompts.json`에 저장합니다. |
| 12 | JSON 불러오기 | `prompts.json`을 읽어 현재 목록에 덮어씁니다. |
| 13 | Markdown 내보내기 | 카테고리별로 묶어 `prompts_by_category.md`로 내보냅니다. |
| 14 | 종료 | 인사 문구를 출력하고 끝냅니다. |

잘못된 번호를 입력하면 안내 후 메뉴로 돌아옵니다.

## 데이터 구조

전체는 리스트, 한 건은 딕셔너리입니다.

```python
{
    "title": "블로그 초안 작성",
    "content": "주제를 바탕으로 블로그 초안을 작성하세요.",
    "category": "텍스트 생성",
    "favorite": True,
    "view_count": 0,
}
```

기본 예시 10개가 `텍스트 생성 · 이미지 생성 · 영상 생성 · 페르소나 · 자동화 · 기타` 6개 카테고리를 모두 포함합니다. 새 항목은 `favorite=False`, `view_count=0`으로 시작합니다. 카테고리 선택에서 `0`을 고르면 직접 입력할 수 있고, 이후 조회 목록에도 나타납니다.
