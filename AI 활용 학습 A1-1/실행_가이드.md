# 실행 가이드 | 준비부터 제출까지

처음 시작하는 순서대로 정리했습니다. Windows는 `python`, macOS·Linux는 `python3`을 씁니다.

## 1. 준비 (한 번만)

| 항목 | 확인 방법 |
| --- | --- |
| VSCode | 앱 실행 |
| Python 3.10 이상 | `python3 --version` |
| Git | `git --version` |
| Python 확장 | VSCode Extensions에서 `Python` 검색 (Microsoft) |
| GitHub 로그인 | VSCode 좌측 하단 계정 아이콘 |
| Korean Pack | 선택 사항 |

```bash
python3 --version
git --version
git config --global user.name "이름"
git config --global user.email "메일"
git config --global init.defaultBranch main
```

## 2. 저장소 내려받기

방법 A. VSCode 명령 팔레트: `Ctrl+Shift+P` → `Git: Clone` → 저장소 주소 입력 → `Open`.

방법 B. 터미널:

```bash
git clone <저장소-주소>.git
cd <저장소-폴더>
```

## 3. 프로그램 실행

반드시 **Terminal > New Terminal**에서 실행합니다.

```bash
cd "AI 활용 학습 A1-1"
python3 prompt_manager.py
```

처음 실행하면 기본 10개와 메뉴 `1`~`14`가 보입니다.

### 직접 사용해 보기

| 순서 | 입력 | 확인 |
| --- | --- | --- |
| 1 | `2` | 기본 10개와 ⭐·조회수 표시 |
| 2 | `1` → 제목·내용·카테고리 | 새 항목 등록 (예: `회의록 요약` / `자동화`) |
| 3 | `4` → `회의` | 제목·내용 검색 |
| 4 | `5` → 번호 | 전체 내용 보기 + 조회수 1 증가 |
| 5 | `6` → 번호 | 즐겨찾기 토글 |
| 6 | `7` | ⭐만 모아서 보기 |
| 7 | `8` → 번호 → `y` | 프롬프트 삭제 (`n`이면 취소) |
| 8 | `9` → 번호 → 새 값 | 프롬프트 수정 (Enter면 유지) |
| 9 | `10` | 조회수 Top 5 |
| 10 | `11` / `12` | `prompts.json` 저장 / 불러오기 |
| 11 | `13` | `prompts_by_category.md` 내보내기 |
| 12 | `14` | 종료 |

저장·불러오기를 쓰지 않으면 추가·수정·삭제·즐겨찾기 변경은 이번 실행에서만 유지되고, 재실행하면 기본값으로 돌아옵니다.

## 4. 테스트

A1-1 폴더에서 실행합니다.

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile prompt_manager.py
```

전부 `ok` + 마지막 `OK`면 통과입니다.

## 5. 수정 후 GitHub에 올리기

```bash
cd ..                       # 저장소 최상위로 이동
git pull origin main
git status
git add "AI 활용 학습 A1-1"
git commit -m "feat(A1-1): 변경 내용을 한 줄로"
git push origin main
```

작게·자주, 기능 단위로 커밋합니다. VSCode Source Control 패널로 해도 됩니다.

## 6. 충돌이 나면

같은 위치를 양쪽에서 다르게 고쳤다는 뜻입니다. 오류가 아니라 사람이 고르라는 신호입니다.

1. `git status`로 충돌 파일 확인
2. 파일에서 `<<<<<<<` / `=======` / `>>>>>>>` 구간을 찾아 남길 내용만 남기고 표식 삭제 (또는 VSCode의 Accept Current / Incoming / Both 선택)
3. 저장 → `git add` → `git commit` → `git push`

아직 방향을 못 정했으면 `git merge --abort`로 중단하고, 내용을 백업한 뒤 다시 시도합니다. `git reset --hard`는 작업이 날아가니 쓰지 않습니다. 막히면 `git status` 출력과 충돌 부분을 보관하고 도움을 요청합니다.

## 8. 자주 생기는 문제

| 상황 | 해결 |
| --- | --- |
| `python3`을 찾을 수 없음 | Python 설치 후 VSCode 재시작, `Python: Select Interpreter`에서 3.10 이상 선택 |
| Output에서 실행했는데 멈춤 | 통합 터미널에서 실행 (이 프로그램은 `input()` 사용) |
| `ModuleNotFoundError` | 터미널이 `AI 활용 학습 A1-1` 폴더인지 확인 |
| `push` 인증 오류 | VSCode GitHub 로그인 확인 |
| 이전에 고르던 `/usr/local/bin/python3.12` 없음 오류 | 컨테이너·원격 환경에서는 `/usr/bin/python3` 등 해당 환경의 경로로 인터프리터 다시 선택 |
