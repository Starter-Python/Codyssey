# 🎾 스쿼시 ESL 리그 AI 선수 관리 시스템 계획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 스쿼시 ESL 리그 통합 관리 AI 에이전트 |
| 목적 | 대진 생성 자동화 + AI 기반 선수 분석/관리 |
| 대상 | 동아리 임원진(관리자) / 일반 멤버(열람자) |
| 비용 | 0원 (전체 무료 도구 구성) |

## 2. 기술 스택

| 역할 | 도구 | 비고 |
|------|------|------|
| 데이터베이스 | Google Sheets | 선수 DB, 경기 기록, 피드백 로그 |
| 백엔드/알고리즘 | Google Apps Script | 대진 알고리즘, AI 연동, 노션 동기화 |
| 프론트엔드 | Apps Script 웹앱 (HTML/CSS/JS) | 세련된 UI, 반응형 |
| 차트 | Chart.js | 스탯 레이더 차트, 무료 |
| AI | Gemini API (무료 티어) | 관전평 분석, 프로필 업데이트 |
| 보조 뷰 | Notion API | 대진표/결과 자동 동기화 |

## 3. 시스템 구성

### 3-1. 대진 관리 모듈
- 월/목 투표 결과 → 참여자 명단 입력
- 레이팅 기반 대진 자동 생성 알고리즘
- 결과를 웹앱 + 노션에 자동 게시

### 3-2. 선수 DB 모듈
- 기본 정보: 이름, 레이팅, 전적
- **스탯 시스템**: 항목별 점수 (예: 파워/발리/백핸드/체력/전략 등)
  - 초기 점수는 운영자가 직접 부여
  - **총점(스탯 합산)** 으로 전체 실력 순위 산출
- 고정 프로필: 기본 장/단점 (거의 변하지 않는 특성)
- 변동 프로필: 경기별 피드백 누적 기록

### 3-3. AI 코칭 에이전트 (핵심)
- 운영자가 경기 관전평 입력
- AI가 [고정 프로필 + 최근 피드백 + 오늘 관전평] 종합 분석
- 분석 리포트 생성 (개선점, 훈련 추천, 성장 피드백)
- 변동 프로필 자동 업데이트 (RAG 유사 구조)

### 3-4. UI 페이지 구성
| 페이지 | 접근 권한 | 내용 |
|--------|----------|------|
| 메인 (대진표) | 전체 | 이번 주 대진, 결과 |
| 선수 프로필 | 전체 | 레이더 차트, 특장점 카드, 분석 리포트 |
| 전체 랭킹 | 전체 | 총점 기준 실력 순위표 (예쁜 테이블 UI) |
| 관리자 페이지 | 임원진 | 참여자 입력, 관전평 입력, 스탯 수정 |
